# Systems Administration & Automation Projects

A collection of open-source systems administration utilities, infrastructure automation scripts, and operational tooling designed to improve reliability, streamline routine maintenance, and enforce consistent security practices.

## Overview

Built on 15 years of hands-on systems administration and IT infrastructure experience, this repository provides practical, lightweight tools for server management, environment auditing, access control, and automated task execution. Each utility is structured for clarity, minimal external dependencies, and safe deployment in production or homelab environments.

## Core Focus Areas

* **Infrastructure & Server Automation:** Scripts for system health checks, log rotation, service monitoring, and repeatable configuration management.
* **Access & Permission Management:** Tooling to audit user roles, enforce least-privilege access controls, and automate onboarding/offboarding workflows.
* **Security & Hardening:** Configuration baselines, web server rule sets, and automated validation checks to reduce misconfigurations and exposure risks.
* **Operational Tooling:** Lightweight command-line utilities and bot integrations that eliminate repetitive manual administration tasks.
